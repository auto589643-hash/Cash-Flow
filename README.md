# CA$HFLOW Meetup Web Mockup

Mobile-first interactive mockup for the CA$HFLOW Meetup registration experience.

## Included

- Public event landing page
- Two-step registration flow
- Pending-review confirmation state
- Admin applicant workflow
- Check-in mode
- Self-contained cartoon hero artwork embedded in `index.html`

## Run locally

Open `index.html` in a modern browser.

## Status

Prototype / UX mockup only. Supabase, email delivery, QR generation, and production authentication are not connected yet.
